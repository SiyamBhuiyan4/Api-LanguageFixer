# BanglaWrite AI — Native macOS Desktop Utility 🇧🇩

> **A 100% native, ultra-lightweight system-wide Bengali AI rewriting tool for macOS.**  
> Built for macOS 12 Monterey on the **2017 Intel MacBook Air** (1.8GHz Dual-Core i5, 8GB RAM).  
> **No Electron. No web wrappers. Native Swift.**

---

## 🌟 How It Works

The app runs in the menu bar from when you open it until you quit it. Select text in any app, then press:

| Shortcut | Result |
| :--- | :--- |
| **⌘⇧B** | Bangla, in your own accent, with grammar fixed and । and commas added |
| **⌘⇧E** | English, in the same tone, with grammar and prepositions fixed |

```text
ami ajke jete parbo na kalke gele ki hobe
→ ⌘⇧B: আমি আজকে যেতে পারব না, কালকে গেলে কি হবে?
→ ⌘⇧E: I can't go today, what if I go tomorrow?
```

If the selected text can't be edited, or you switch apps before the answer arrives, nothing is replaced. A floating card shows the result with a Copy button instead.

### 🛡️ Safety & Workflow Protection
- **No auto-submit:** The app **never** presses Enter, never clicks Send, and never submits a form. You always perform the final action manually.
- **Clipboard safe:** Uses transient pasteboard markers (`org.nspasteboard.TransientType`, `ConcealedType`, `AutoGeneratedType`) and restores your previous clipboard history automatically.
- **Cross-App compatibility:** Works seamlessly across **Notes, TextEdit, VS Code, Google Chrome, Safari, WhatsApp, Discord, Slack, Messenger, Gmail, and Microsoft Word**.

## ⚡ Quick Start

### 1. Build & Install
```bash
cd /Users/mdyeakubsarker/Documents/Agent-bangla/mac-app
make install
open /Applications/BanglaWriteAI.app
```

The Bengali **অ** icon appears in your menu bar. To quit, open that menu and choose **Quit BanglaWrite AI**.

### 2. Turn On Accessibility
In Settings, click **Turn On…**, then enable **BanglaWriteAI** in System Preferences → Security & Privacy → Privacy → Accessibility.

Every rebuild changes the app's signature, so macOS stops trusting it. After `make install`, turn the permission off and on again. If that doesn't help, remove the entry and add it again.

### 3. Add Your Gemini API Key
Click the **অ** icon → **Settings...**, paste your key, click **Test**, then **Save**. Come back here any time to change the key, provider, or model. A successful test fills the **Choose** menu with the models your key can use.

Other providers: Groq, OpenAI, Ollama, any OpenAI-compatible endpoint, and a basic offline engine that does Bangla only.

## 🎭 Writing Styles

The default is **Keep My Voice**. Switch any time from the menu bar or Settings:
1. **Keep My Voice (যেমন লিখেছি তেমন)** — *Default:* Same words and accent; only mistakes change.
1. **Natural Bangla (প্রাকৃতিক বাংলা)** — Everyday natural phrasing.
2. **Polite Bangla (ভদ্র / বিনয়ী)** — Gentle, respectful Bengali with courteous markers.
3. **Professional Bangla (পেশাদার)** — Polished, workplace-ready Bengali.
4. **Casual Bangla (অনানুষ্ঠানিক / ঘরোয়া)** — Friendly tone for chat & friends.
5. **Formal Bangla (আনুষ্ঠানিক / প্রাতিষ্ঠানিক)** — Formal Bengali for official letters and documentation.
6. **Shorten (সংক্ষিপ্ত)** — Crisp, concise communication preserving core meaning.
7. **Fix Grammar (ব্যাকরণ শুদ্ধ)** — Pure grammatical and spelling correction.

## 🛠️ Developer & Terminal Commands

| Command | Action |
| :--- | :--- |
| `make all` | Full build, code sign, and run the verification tests |
| `make test` | Run the native Swift test runner suite |
| `make run-app` | Launch the macOS menu bar bundle (`BanglaWriteAI.app`) |
| `make run-cli` | Launch the background daemon in standalone CLI mode |
| `make install` | Install directly into `/Applications/BanglaWriteAI.app` |
| `make clean` | Clean build artifacts |

### Standalone Python Companion
If you prefer running a command-line script without the Cocoa app bundle:
```bash
# Rewrite selected text from the terminal
python3 banglawrite.py -s

# Direct text transformation
python3 banglawrite.py "apu ajke product ta pathaite parbo na kalke pathabo" -m professional
# Output: আপু, আজকে প্রোডাক্টটি পাঠানো সম্ভব হচ্ছে না। আগামীকাল পাঠিয়ে দেব।
```

## 🔒 Privacy & Local Security
- Config is saved locally at `~/.banglawrite/config.json` with POSIX `0600` permissions (read/write only by your user account).
- Text is **only** captured when you strike the hotkey. No keylogging, no screen monitoring, no background tracking.
- Network requests use ephemeral URL sessions without disk caching.
